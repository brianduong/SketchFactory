Privacy Policy

SketchFactory Uploader · Last updated 3 September 2026

What this application is

SketchFactory Uploader is a personal command-line tool. It renders drawing tutorial videos and uploads them to a single YouTube channel, Simple Sketch, owned by the same person who runs the tool. There is no website to sign into, no user account system, and no other person is asked to authorise it.

What data it accesses

When the owner authorises the tool through Google, it receives the https://www.googleapis.com/auth/youtube.force-ssl scope. It uses that access only to:

  • upload video files to the owner's own YouTube channel;
  • set each video's title, description, tags, thumbnail, caption track, privacy status and scheduled publish time;
  • create playlists on that channel and add the owner's videos to them;
  • read back the status of videos it uploaded, to confirm the upload succeeded.

It does not read, collect, or process any other person's YouTube data, viewing history, subscriptions, comments, or personal information.

Where data is stored

The OAuth access and refresh tokens are stored in a single file on the owner's own computer. They are never transmitted anywhere except to Google's own APIs, and they are not stored on any server. Video files, thumbnails and subtitles are produced locally and sent directly to YouTube.

What is not done with the data

No data obtained through the Google APIs is sold, rented, shared with third parties, used for advertising, used to build profiles, or used to train any model. There are no analytics, trackers, or cookies on this site.

Retention and deletion

Authorisation can be withdrawn at any time from the Google Account permissions page, which immediately invalidates the stored tokens. Deleting the local token file has the same effect on this end.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
